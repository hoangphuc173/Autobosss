?? DEPLOYMENT OPTIONS:

OPTION A: Auto Deploy (Recommended)
1. Open PowerShell in THIS folder
2. Run: .\deploy.ps1
3. Select your game from the list
4. Done!

OPTION B: Manual Deploy
1. Find your game folder:
   - Open Steam ? Right-click game ? Manage ? Browse Local Files
   - You should see: [GAME_NAME].exe and BepInEx folder

2. Navigate to: BepInEx\plugins\

3. Copy these 2 files to plugins folder:
   ? AutoBossGrabber.dll
   ? AutoBossShared.dll

4. Delete old cache (optional):
   - Delete: bfs_map_cache.json (if exists)

5. Launch game!
